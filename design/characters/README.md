# 原創像素素材

角色為貓、恐龍、狗、達摩、哥布林；原創24×24格點，五動作×四表情×雙影格，共200張App動作PNG及可編輯SVG。幼體與成體採不同顯示尺寸，死亡共用墓碑。可編輯來源與manifest位於本目錄及animation/；產生工具在scripts/make-*.py。來源沿用根目錄BSD-3-Clause，字型另依OFL。

`scripts/make-pet-animation.py`維護貓／恐龍，`scripts/make-extra-pets.py`維護狗／達摩／哥布林；`scripts/check-extra-pets.py`逐格核對新物種PNG／SVG／manifest一致性。動畫只改呈現，不自行完成照顧、成長或復活。
