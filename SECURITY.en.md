# Security policy

[繁體中文](SECURITY.md) · [English](SECURITY.en.md) · [日本語](SECURITY.ja.md)

## Official source

Source: https://github.com/chayawang/Tomatogotchi

The only official App download channel: https://github.com/chayawang/Tomatogotchi/releases

Apps from other accounts, mirrors, or forks are not official releases. Legitimate modification and redistribution remain governed by LICENSE; third-party versions are not endorsed. Compare the official SHA-256. A matching hash does not guarantee the absence of vulnerabilities or absolute safety.

## Private reporting

Use **Security → Advisories → Report a vulnerability** in this repository, or the [private reporting page](https://github.com/chayawang/Tomatogotchi/security/advisories/new). If unavailable, open a public Issue without vulnerability details to ask for a private contact method. Do not publish exploitable steps, passwords, tokens, verification codes, or private pet saves.

Include the affected version, macOS version and architecture, impact, and reproduction steps using separate test data. Coordinate disclosure before a fix is available. Do not access other people's data or test devices you do not own without permission. Use Issues for general feature problems.

## Support scope

The current public prerelease is 1.0.2 build31. Security work focuses on the latest official version; backports for older or third-party versions are not promised. The maintainer will assess reports but does not promise a fixed response or repair deadline, or freedom from vulnerabilities.

The package uses ad-hoc signing and is not Apple-notarized. Read the release limitations. Do not disable system protections globally. Stop installation and report the source and filename if warned about malware or damage; do not simply bypass the warning.
