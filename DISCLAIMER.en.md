## Safety and scam prevention

This version does not require an Apple ID password, bank account, credit card details, one-time verification code, or cryptocurrency wallet recovery phrase for activation. It does not request an unlock fee, deposit, or verification payment through private messages.

Stop if asked to install an unfamiliar configuration profile, grant remote control, or disable system security to install. Return to the official pages above to verify the request. Do not run a file merely because its name or appearance matches.

Before installation, compare the version, filename, and SHA-256 published on the official Release. Obtain the reference hash directly from the official page; a hash supplied by a third party does not prove provenance. Do not execute files with mismatched checksums, unknown origins, or contents inconsistent with the announcement.

A matching SHA-256 establishes matching file contents only. It is not a guarantee of freedom from vulnerabilities or malware, or of absolute safety.
