# インストールと使い方

[繁體中文](user-guide.md) · [English](user-guide.en.md) · [日本語](user-guide.ja.md)

現在のAppの表示言語は繁体字中国語です。操作箇所を見つけやすいよう、以下に実際のラベルを併記します。

## ダウンロードと起動

公式Appの唯一のダウンロード先：https://github.com/chayawang/Tomatogotchi/releases

1.0.2 build31はApple Silicon専用の公開テスト版です。Developer ID署名・Apple公証はありません。ファイル名と公式SHA-256を確認し、任意の場所へ解凍して開いてください。更新前に旧Appを終了し、データをバックアップしてください。正式利用のAppを複数同時に起動しないでください。

開発元未確認や未公証を理由にmacOSがブロックした場合、まず配布元とリスクを確認してください。信頼すると判断した場合は[Appleの説明](https://support.apple.com/102445)に従い、「システム設定 → プライバシーとセキュリティ」でこのAppの「このまま開く」を選択します。表記はOSによって異なります。MacやApple IDのパスワードを公開者に渡す必要はありません。マルウェア、破損、コンピュータへの損害に関する警告が出た場合は中止し、報告してください。Gatekeeper全体を無効化したり、会社の管理ポリシーを回避したりしないでください。ダウンロード後の実際のGatekeeperインストール手順は手動検証が未完了です。

## 卵を迎えて作業する

未知の卵を迎え、任意で名前を付けます。後から変更も可能です。電子ペットのメニュー「每輪時間」（ラウンド時間）で、作業・休憩をそれぞれ1～1440分に設定できます。候補は作業10／20／30／60分、休憩5／10／15分です。設定を適用してから作業を開始してください。途中で変更する場合は、先に現在の作業を終了します。

作業時間が終わると、食事または散歩の要求が表示されます。応じると休憩が始まります。応答せずに有効な待機時間が累計3分経過するごとに、健康または気分が1減り、どちらかが0になると死亡します。一時停止、作業終了、スリープ、ロック、App終了、オフライン中の時間を後から減点することはありません。完全な休憩3回で孵化し、12回で成体になります。未知の卵は5種類のいずれかに固定され、再起動しても抽選し直しません。

## モードと散歩

本体サイズは元の80%です。メニューの「只顯示寵物」（ペットのみ表示）で切り替え、ペットを右クリックすると通常ウィンドウに戻せます。作業中は待機・歩行・睡眠・遊びをランダムに表示し、ペットのみのモードでも移動は小範囲です。「帶牠晃晃」（散歩に連れていく）に応じると、現在の画面の利用可能なデスクトップ内を平面移動し、端で方向を変え、時間が来ると元の位置に戻ります。ドラッグを優先し、モードを変えても同じ休憩時間を引き継ぎます。非表示や「視差効果を減らす」が適用される場合は視覚的な移動を停止します。既存の最前面表示設定も利用できますが、実際のマウス操作、クリック透過、OSイベント、複数画面での見え方は手動確認が残っています。

## 亡くなったペットの記録

電子ペットのメニュー、ペットのみ表示での右クリック、メニューバーから「死亡寵物紀錄」（亡くなったペットの記録）を開けます。墓石に死亡総数、名前、卵を迎えた出会いの日時、死亡日時を表示します。死亡時点で記録され、お別れして新しい卵を迎えた後も残ります。再起動で重複せず、記録を閉じても元のモードやタイマーは変わりません。一部のデータを読み込めない場合は、不完全な読み込みであることを明示します。

## データとバックアップ

標準の保存先は自分のアカウントの`~/Library/Application Support/Tomatogotchi/`です。`pet.json`、`care.json`、`desktop.json`、お別れの保存履歴`pet-history`を含みます。実際の保存先はAppが選択し、QAは別の場所を使います。更新・削除前にAppを終了し、フォルダ全体をバックアップしてください。公開Issueに個人のセーブデータを貼らないでください。読み取りエラー時は元のファイルを保持し、Appの再試行・バックアップ復元を使ってください。テストでは専用QAツールを使い、正式なペットデータを読み書きしないでください。

## その他

自動更新はありません。非表示と終了は異なります。終了するにはメニューの「結束App」を使います。通知はmacOSで本人の許可が必要で、拒否できます。Apple ID、銀行情報、有料の認証保証金は不要です。一般的な問題は公式Issues、脆弱性は[SECURITY](../SECURITY.ja.md)の非公開窓口へ報告してください。
