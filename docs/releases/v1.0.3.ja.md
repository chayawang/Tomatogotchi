# v1.0.3 公開テスト版（build38）

[繁體中文](v1.0.3.md) · [English](v1.0.3.en.md) · [日本語](v1.0.3.ja.md)

公式ダウンロード：https://github.com/chayawang/Tomatogotchi/releases

2回目の公開テスト版です。v1.0.2の5種類、デスクトップ散歩、死亡記録に加えて、次を変更しました。

- 穏やかな本体アニメーションまたは強い中央ポップアップを選択。両方でシステム通知を維持。
- 作業終了後、最初の食事／散歩の応答保存で孵化。非表示時は卵を表示してから再生。
- 作業中の時間変更制限を明記。休憩中は現在の残り時間を変えずに次の設定を変更可能。
- 従来の長方形の領蛋・命名画面を維持し、本体に配色を統一。

終了アニメーションの余分な枠線は完全には除去されていません。死亡・お別れのUXは本版では変更していません。

## ビルドと検証

バージョン1.0.3、build38、arm64（Apple Silicon）。宣言上の最低要件はmacOS 13、実機テストの基準はApple Silicon／macOS 14.4.1です。ソースのcommit、署名状況、アーキテクチャは、パッケージのrelease-metadata.jsonと公式Releaseを確認してください。

正式な自動検証入口は`bash scripts/verify.sh`です。コア・App共有モデル、保存互換性・死亡・成長、作業・散歩、5種類のキャラクター描画1790件、本体・ボタン76件、死亡記録画面12件、新素材120件の整合性、独立プロセス・ウィンドウ、動作中のSwiftUIタスク、Releaseビルド、厳格なad-hoc署名検証を含みます。`python3 scripts/check-release.py`は解凍後のパッケージ、データ保全、移動後の再起動も確認します。今回の実際の結果は公式Releaseの記録を参照してください。

## 制限事項と未検証項目

- ad-hoc開発署名です。Developer ID署名・Apple公証はありません。codesign検証の合格はApple認証ではありません。
- ダウンロード後のFinder／Gatekeeperインストール、実際のマウス・スクロール操作、OSのロック・スリープ・設定、複数画面や主観的な見え方は手動確認が残っています。自動・注入イベントを実際のOS操作の検証とみなしません。
- Intelと最低macOS 13での実機検証は未実施で、Intel用バイナリは含みません。
- 自動更新はありません。更新前に旧版を終了し、データをバックアップしてください。公開パッケージにサンプルや実際のペットの保存データは含みません。

管理対象のMacでブロックされた場合は管理者のポリシーに従い、システム保護全体を無効化しないでください。一般的な問題はIssues、脆弱性や機密情報は[セキュリティポリシー](../../SECURITY.ja.md)の非公開窓口へお願いします。
