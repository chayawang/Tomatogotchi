# v1.0.3 public prerelease (build38)

[繁體中文](v1.0.3.md) · [English](v1.0.3.en.md) · [日本語](v1.0.3.ja.md)

Official downloads: https://github.com/chayawang/Tomatogotchi/releases

This second public prerelease retains the five species, desktop walks, and memorial records from v1.0.2 and adds:

- Gentle device animation or a strong central popup, with system notifications in both modes.
- Hatching on the first successful feed/walk response after work ends; hidden windows reveal the egg first.
- Clear duration-lock guidance during work and next-round settings during rest without changing the current countdown.
- The original rectangular adoption/naming layout with device-matched colors.

The completion animation may still show an extra outline; its full removal remains unfinished. The death/farewell UX is unchanged.

## Build and verification

Version 1.0.3, build38, arm64 (Apple Silicon). The declared minimum is macOS 13; the physical test baseline is Apple Silicon/macOS 14.4.1. See the package's release-metadata.json and official Release page for the source commit, signing status, and architecture.

The canonical automated entry is `bash scripts/verify.sh`. It covers core/shared App models, save compatibility/death/growth, work/walking, 1,790 character renders across five species, 76 device/button renders, 12 memorial screens, 120 new asset consistency checks, separate processes/windows, live SwiftUI tasks, release builds, and strict ad-hoc signature checks. `python3 scripts/check-release.py` additionally checks extracted packages, data preservation, and restart after relocation. Consult the official Release record for the actual results of this release.

## Limitations and pending checks

- Ad-hoc development signature, without Developer ID or Apple notarization. Passing codesign verification is not Apple certification.
- Downloaded Finder/Gatekeeper installation, physical mouse/scroll input, real OS lock/sleep/preferences, multi-display behavior, and visual impressions still require manual checks. Automated or injected events are not real OS interaction coverage.
- Intel and minimum macOS 13 have not been physically tested; the download does not contain an Intel build.
- No automatic updates. Quit the previous version and back up your data before updating. Public packages contain no demonstration or real pet saves.

On a managed Mac, follow the administrator's policy if installation is blocked; do not disable system protection globally. Use Issues for general problems and the private channel in the [security policy](../../SECURITY.en.md) for vulnerabilities and sensitive data.
