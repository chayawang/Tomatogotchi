## 建置與驗證

版本1.0.3，build38，arm64（Apple Silicon）；最低宣告macOS13，實機基準Apple Silicon／macOS14.4.1。公開來源對應的git commit、簽章狀態與架構見套件release-metadata.json及Release頁。

`bash scripts/verify.sh`為正式自動入口，涵蓋核心、App共享模型、保存相容／死亡／成長、工作與散步、五物種1790角色渲染、76機身與按鍵、12死亡紀錄畫面、120新素材一致性、獨立程序／視窗與活體SwiftUI任務、Release及嚴格ad-hoc簽章。`python3 scripts/check-release.py`另驗證解壓後套件、資料保全與搬移重開；實際本次結果以官方Release記錄為準。

## 限制與未驗項目

- ad-hoc開發簽章，未Developer ID／未Apple公證；codesign通過不是Apple認證。
- 下載後Finder／Gatekeeper安裝、真實滑鼠與捲動、OS鎖定睡眠／偏好、多螢幕及主觀觀感仍有人工pending；自動或注入事件不冒充真實OS操作。
- Intel及macOS13最低版本未實機驗證，下載包不含Intel。
- 無自動更新，更新前退出舊版並備份資料。公開套件不含示範或正式寵物存檔。

在受管制Mac上若公司政策阻擋，請依管理員政策處理，不要關閉整體系統防護。一般問題可提Issue；漏洞與敏感資料透過安全政策的私人管道。
