# Tomatogotchi 使用與安裝

[繁體中文](user-guide.md) · [English](user-guide.en.md) · [日本語](user-guide.ja.md)

## 下載與開啟

唯一官方 App 下載頁：https://github.com/chayawang/Tomatogotchi/releases

本版是1.0.3 build38公開測試版，僅提供Apple Silicon套件，未Developer ID簽章／未Apple公證。請核對檔名及官方SHA-256，解壓至自己選擇的位置後開啟。更新前先退出舊App並備份資料，不要同時啟動多個正式版本。

若macOS因未驗證開發者或未公證而阻擋，請先確認下載來源與風險；決定信任後，依[Apple官方說明](https://support.apple.com/102445)，在「系統設定→隱私權與安全性」對此App選擇「仍要打開」（字樣依版本而異）。不需要把Mac密碼或Apple ID密碼交給發布者。若提示惡意軟體、已損毀或會傷害電腦，請停止操作並回報，不要全面關閉Gatekeeper或繞過公司管理政策。下載後的真實Gatekeeper流程尚未補驗。

## 領蛋與工作

領取未知蛋並選填名字，之後可改名。從電子雞選單「每輪時間」設定工作／休息1–1440分鐘；工作快捷10／20／30／60分，休息快捷5／10／15分。先套用設定，再開始工作。專注中（含暫停）不可調整；休息時可設定下一輪，當前倒數不變，下一次手動開始工作才採用。

時間到時出現餵食或散步需求，回應後進入休息。未回應每累積3分鐘有效等待扣一格健康或心情，任一歸零會死亡。暫停、收工、睡眠、鎖定、關閉與離線不追扣。第一次完整工作結束仍是蛋，第一次按「餵牠吃飯」或「帶牠晃晃」並成功保存後，才播放裂痕、晃動與孵化；只關閉提醒或提早休息不會孵化。累計12次完整休息長大；未知蛋會固定分配五種之一，重開不重抽。

## 到時提醒

設定可選「溫和提醒」或「強烈提醒」：預設以電子雞動態提示，強烈模式另外顯示中央彈窗。請在工作結束前選好模式。兩種模式保留macOS系統通知，實際顯示仍受你的通知權限與系統設定影響。關閉提醒只停止提示，照顧需求仍保留；從隱藏畫面回應首次照顧時，會先顯示蛋再孵化。初次領蛋與命名維持原方形布局，配色跟隨電子雞。

## 模式與散步

電子雞保持80%機身尺寸；選單可切換「只顯示寵物」，純寵物右鍵可回一般視窗。工作時隨機待機／走／睡／玩，純寵物只在小範圍活動；回應真正的「帶牠晃晃」後，純寵物在目前螢幕可用桌面平面走動、碰邊轉向，時間到回原位。拖曳時讓位，模式切換沿用同一段休息；不可見或減少動態等狀態會停止視覺位移。可用既有置頂選項觀察，但真實滑鼠、點擊穿透、OS事件及多螢幕觀感仍有待驗項目。

## 死亡紀錄

電子雞選單、純寵物右鍵及選單列可開啟「死亡寵物紀錄」，墓碑顯示死亡總數、名字、領蛋見面時間及死亡時間。死亡即計入，告別領新蛋後仍保留，重開不重複計數；關閉紀錄不切換原模式或重設計時。部分資料無法讀取時會明示未完整載入。

## 資料與備份

資料預設保存在自己帳號的 `~/Library/Application Support/Tomatogotchi/`，包含pet.json、care.json、desktop.json與告別封存pet-history；實際資料目錄由App選定，QA另有獨立目錄。更新或移除前先退出App並備份完整資料夾。不要將私人存檔貼到公開Issue；讀取失敗時保留原檔，依App提供的重試／備份恢復操作處理。測試請使用獨立QA工具，不讀寫正式寵物。

## 其他

本版無自動更新。隱藏與退出不同；從選單「結束App」退出。通知須由自己在macOS授權，可拒絕；不必提供Apple ID、銀行資料或付費驗證金。一般問題可用官方Issues回報，安全漏洞依SECURITY.md私人通報。
